# Programación y Algoritmos en Java

Repositorio de proyectos académicos desarrollados durante mi formación en Informática.

## Sobre el proyecto

En este repositorio se reúnen diferentes ejercicios y programas desarrollados en Java, con el objetivo de aplicar conceptos de programación, algoritmos y resolución de problemas.

Los proyectos fueron realizados como parte de mi formación académica y como práctica personal para continuar desarrollando conocimientos en programación.

## Tecnologías utilizadas

- Java
- Programación orientada a objetos
- Algoritmos
- Estructuras de datos
- Recursividad
- Arreglos
- HashMap
- PriorityQueue

## Proyectos

### Algoritmos de ordenamiento

Implementación del algoritmo Bubble Sort para ordenar elementos de un arreglo.

Archivo:

`src/AlgoritmosOrdenamiento.java`

Conceptos trabajados:

- Arreglos
- Ciclos
- Métodos
- Comparación de elementos
- Intercambio de valores

### Algoritmos de búsqueda

Implementación de búsqueda lineal y búsqueda binaria.

Archivo:

`src/Busqueda.java`

Conceptos trabajados:

- Búsqueda lineal
- Búsqueda binaria
- Arreglos ordenados
- Ciclos
- Métodos

### Algoritmo de Huffman

Implementación del algoritmo de compresión de Huffman.

Archivo:

`src/Huffman.java`

Conceptos trabajados:

- Árboles
- Frecuencia de caracteres
- HashMap
- PriorityQueue
- Recursividad
- Códigos binarios
- Programación orientada a objetos
